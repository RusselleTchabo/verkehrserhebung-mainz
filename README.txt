Verkehrserhebung Mainz – Offline-Web-App

1. Alle drei Dateien zusammen auf einem HTTPS-Webserver veröffentlichen (z. B. GitHub Pages).
2. Auf dem Handy die HTTPS-Adresse bei bestehender Internetverbindung öffnen.
3. Auf iPhone in Safari: Teilen > Zum Home-Bildschirm. Auf Android: App installieren / Zum Startbildschirm.
4. App einmal vollständig laden. Danach im Flugmodus testen, BEVOR die Erhebung beginnt.
5. CSV regelmäßig exportieren und sichern. Die Daten liegen nur im Browser des jeweiligen Geräts.

Alternativ kann index.html lokal im Browser geöffnet werden; dabei sind Service-Worker-Installation und zuverlässige Offline-Nutzung je nach Browser nicht verfügbar.

Hinweise: Die Liste der Zählstellen 01–43 ist eine editierbare Voreinstellung und keine bestätigte Liste der tatsächlichen Erhebungsstellen. Die Kategorien orientieren sich an den Fotos. Bei Kennzeichen die Datenschutzvorgaben des Projekts prüfen. Die App speichert automatisch die aktuelle Geräteuhrzeit, nicht eine manuell eingestellte historische Uhrzeit.
